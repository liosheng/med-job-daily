还有哪些路可以走 · 14 条非临床路线，逐条说清干什么、卡在哪
药物警戒 PV 性格合适
收药企/医院报上来的不良反应病例，判断和药有没有因果关系，录进安全数据库、定期写汇总报告。国家强制要求每个上市药品都配人做这件事，所以岗位稳定、不受集采和销售指标影响。
门槛：本科临床医学够门槛，不要求执业证；卡人的是英文——病例报告、MedDRA 词典、公司 SOP 大量是英文。CET-4 能读写就能起步。
和你：整份工作对着病例和系统，一天说不了几句话，同事是药师和医学经理。这是全表里和你性格最不冲突的一条。
临床数据管理 CDM 性格合适现在 0 条
给临床试验建数据库，把各家医院录进来的数据清一遍：缺的、矛盾的、超范围的值，写成疑问发给 CRC 去问医生。整个试验的数据质量由你负责。
门槛：本科可入，CET-4；要会用 EDC 系统（公司会教），细心比聪明重要。
和你：纯后台，不接触客户也不进病房，节奏是项目制的。缺点是前期重复劳动多，要坐得住。
注册专员 RA 性格合适
把产品的安全性、有效性资料整理成药监局要求的格式递上去，跟审评老师沟通、补资料。器械、药品、化妆品都有这条路。
门槛：本科可入，不需要执业证；要肯啃《医疗器械注册与备案管理办法》这类法规原文。前两年基本在写资料。
和你：坐办公室写材料，对外只对审评和内部研发，不背销售指标。成长慢但越老越值钱。
质量 QA / QC 性格合适
QA 管体系：文件、记录、内审、批放行；QC 管检验：按药典/行标做检测、写原始记录。
门槛：本科可入，GMP/GSP 之类靠进厂后培训；QC 要动手做实验，QA 要较真。
和你：工厂/实验室环境，人际简单，评价标准是「有没有按 SOP 做」，不是「客户喜不喜欢你」。
医学写作 / 医学编辑 要付代价
写说明书、临床评价报告（CER）、学术稿、患者教育材料；把医生和研发说的话整理成合规文本。
门槛：本科能进的是国内 CRO、医学媒体、器械厂的注册部；外企医学写作岗普遍要硕士或英语专八。CET-4 只能从国内小公司起步。
和你：活是纸面活，性格上很配；卡你的是英语和学历，起步薪资也偏低（6–9K）。
病案编码 / DRG 专员 性格合适
把出院病历里的诊断和手术，按 ICD-10 / ICD-9-CM-3 编成码，直接影响医院医保能结多少钱。DRG 付费改革后这类人很缺。
门槛：本科临床医学是优势（看得懂病历），但要另考编码员证或参加院内培训；医院病案室多为合同制。
和你：对着病历和编码库，几乎不见外部客户。医院里最安静的一类岗，稳定。
医学审核（互联网医疗） 性格合适
审核平台上医生的执业资质、科普内容、问诊回复是否合规；也做医学知识库的标注和校对。
门槛：本科可入，要熟悉医师执业注册信息和常见诊疗规范。
和你：内容审核类岗位，按规则判对错，不用跟人争论；缺点是天花板不高，容易被当成成本中心。
CTA / TMF 文档管理 性格合适
管临床试验的全部文档：伦理批件、研究者简历、培训记录，按 TMF 目录归档，随时能应对稽查。
门槛：本科可入，英语能读文档即可；非常适合当进 CRO 的第一块跳板。
和你：纯粹的文件管理，不跑医院不见客户。钱少（4–7K），但一年后转 CRA/项目管理比外面直接投容易。
CRC 临床协调员 要付代价
在指定的一家医院里，帮研究者（医生）处理试验事务：筛受试者、约随访、填 CRF、整理原始资料。
门槛：本科可入，护理/临床背景都收；不需要执业证。
和你：固定在医院里，对象是一小圈熟悉的医生护士，不是陌拜。但医生忙起来会催你、凶你，你要能扛住当面压力。
医助 / 医生助理 要付代价
跟着主诊医生做术前准备、换药、写病历、术后回访。医疗美容、口腔、中医门诊最多。
门槛：本科可入，不需证；但雇主标了「需助理医师执业证」的岗你现在投不了。干满一年可以报考执业医师，这是绕回临床的一条路。
和你：对人是固定的一小圈，不是陌拜。但起薪低（5–8K）、杂事多，而且要在医生手下做配合，看你受不受得了这种位置。
CRA 临床监查员 不建议
负责几家医院的临床试验质量：定期去现场核对数据、查原始病历、写监查报告、催研究者整改。
门槛：本科可入，是临床医学本科最主流的非临床去向；出差多（一个月一半在路上）。
和你：要跑多家医院，虽然是和医生打交道不是陌拜，但一年出差一百多天、同时被项目经理和医院两边推。你说在意环境稳定，这条先放后面。
临床应用 / 产品培训 要付代价
教医生护士怎么用公司的设备/耗材，做科室会、操作演示、术后回访。不背硬销售指标（部分公司背）。
门槛：本科可入，临床背景是硬优势；要能站上台讲。
和你：对着一屋子医生讲课，是「被围观和评价」的场景。你有救护师资授课经历，能扛，但确实消耗。
技术专员 / 手术跟台 不建议
器械公司的技术专员，手术时站在台边递器械、调设备、教医生用新产品。
门槛：本科可入；多数公司要求能接受随时被叫去手术室。
和你：你说得对：台次不定、下班跟着手术走，介入类还有射线暴露。这类岗收入不低，但拿的是身体和时间。
销售（ToB / 医美 / 药代） 不建议
开发医院或经销商，完成进货指标。医美销售卖设备或项目，药代卖药。
门槛：本科可入，外企药代待遇最好但面试看沟通和抗压。
和你：核心动作就是陌拜和背指标，还要被客户、主管、数字三方面打分。你自己说在意周围评价——这条会天天磨这件事。

收录标准：分「医疗健康」和「跨行业」两个板块。医疗板块＝上海与浙江在招岗（含全国多城）；本科可投、无执业医师证与规培证也能进；已排除药店 OTC、带金医药代表、保险理财类销售；硕士起投的不收。江苏的岗位暂时整省收起（源数据一条没删，只是这一版不展示），之后要看随时能放回来。

核验方式：每条都实际打开过原链接，看的是页面标题里有没有这个职位名——平台页底部推荐位到处都是公司名，只搜公司名会把已下架的岗也判成在招。链接 404、页面写已下线、或落到校招总览页/搜索页的，一律不收。

时效：原页面发布时间超过一年的一律剔除——猎聘上还留着 2020 年挂的岗，点得开但早招完了。页面明写职位有效期的，按有效期判。

「长期在招」是什么意思：原页面发布至今满 60 天还没撤，卡片上会标「挂了 N 个月」；满半年标红「长期在招·N 个月」，快捷栏「长期在招」一次筛出全部（现在 ${STATS.long} 条，半年以上 ${STATS.longx} 条）。你问的「招这么久是不是因为人待不住」，方向对，但不能一句话盖死，同一个「挂了 4 个月」背后至少三种情况：① 流动快——进去的人干不久，一直在补位，这是真信号，值得警惕；② 门槛高——要证、要特定经验，符合的人本来就少，招久正常，不代表岗烂；③ 常备池——HR 常年收简历、不急招，投了容易被搁着。数据里能区分的只有「有没有人在处理」：招聘方最近上线时间近的，标「·仍在收」；几十天不上线的，另有「HR N 天没上线」的标。真正的判断得靠面试时问三句：这个位置上一任做了多久、为什么走、现在团队里同岗位有几个人。别只凭「招得久」就把岗划掉，也别因为它是大厂就忽略这个信号。

已投递标记：每张卡右下角有「标记已投递」，点一下这张卡会变灰、按钮变成 ✓，再点一次取消。标记只存在你自己浏览器的 localStorage 里，不上传、不联网，换设备或清缓存会丢。筛选项里的「只看未投递 / 只看已投递」就是按这个标记过滤的。每天更新不会弄丢标记：站点同时按「岗位 id」和「公司+标题」存两份，岗位换来源、合并时换了主记录导致 id 变化，也能自动认回来（页面上会提示「已自动找回 N 条」）；岗位下架后卡片不显示，但记录留在下方「我的投递记录」里，重新上架时仍然是「已投递」。

招聘方有没有在看：岗位挂着不等于有人在收简历。智联详情页里有招聘方的最后上线时间，猎聘写「X 天前在线」，本站直接读这两个字段——超过 30 天没登录的不收录（投了也是石沉大海），7 天以上的会在卡片上标出来。碰到「岗位刚发布、HR 却几十天没上来」的，多半是平台自动刷新了旧岗位。

来源有哪几家：① 智联招聘公开招聘页，脚本每日抓取并核验；② dr.ai998.top 整理的清单，本站收录前逐条重验原链接；③ 康强医疗人才网，只取它公开列表；④ BOSS 直聘，匿名访问公开搜索页、按「关键词×城市」横向收，抓不到薪资和发布日期（见下方专门说明）。带“展开职责与要求”的卡片含对方整理的 JD 原文，仅供参考，投递前以原页面为准。

顶部那排快捷按钮：筛选区收起时，横条下面那一行是常驻的——今日新增 / 未投递 / BOSS直聘 / 少对生人 / 不陌拜 / 跨行业 / 小而美 / 已投递。这些按钮可以同时点亮好几个：同一条横线里的条件取并集，不同横线之间叠加。比如「今日新增」＋「未投递」＝今天新来的、我还没投的；「BOSS直聘」＋「不陌拜」＝BOSS 上不用开发陌生客户的岗。点一下选中，再点一次取消，「已投递 / 未投递」互斥（选一个会把另一个拿掉）。点完页面会跳到列表开头，不用先展开筛选。其中「今日新增」按「本站第一次抓到它的那天」算，不是招聘方自己标的发布日期——两者的差在于：一个新来源刚接进来的那天，会把它的存量岗一起算成「新增」（那天数字会跳一下），之后每天的数字才是真实的日增量。康强和 BOSS 这两批尤其如此，它们都拿不到可信的发布日期。

BOSS 直聘这批是怎么进来的，哪些信息不全：用真实 Chrome 匿名打开搜索页，再在页面里连发它的搜索接口，不登录、不碰你的账号。匿名能看到的比登录少三样，页面上一律如实标：① 薪资被隐藏（列表和详情页都只给一个「元」字，数字由服务端抹掉），所以这类岗写「未公开」而不是「面议」——面议是招聘方的选择，未公开是平台对我们隐藏；② 每个查询只能看到第一页 15 条（翻第 2 页服务端直接返回空），覆盖面靠「多查询词 × 多城市」铺开，不是翻到底；③ 列表没有发布日期，所以不参与「长期在招」的判断。反过来，它在列表里出现就等于在招，比智联的 jobStatus 更直接。

「板块」为什么要分医疗和跨行业：医疗那批是「专业对口」，跨行业那批不是——美妆功效评价、第三方检测、直播运营、内容剪辑、服装买手/跟单。你要的原话是「只要有兴趣的、有发展前景的、履历能进或者努努力能上的都可以」，所以这一栏收的不是「所有非医疗岗」，而是过三道筛的：① 有兴趣（就这五族，别的不收）；② 有前景（门店服务、出镜主播、纯销售、要科班作品的设计师，一律不收，因为它们没有下一步）；③ 够得着（门槛分「能进」和「够一够」两档，现在进不去的直接不出现在列表里）。跨行业岗不标「匹配度」——专业本来就不对口，标个低分只会误导；它们标的是门槛。

「门槛」这两个字比「匹配度」重要：能进＝按学历、经验、证书看，现在这份简历投得进，拼的是面试表现；够一够＝要先补点东西才说得上话（作品集、软件、或一两段相关经历），不是投了就进。第三档「现在进不去」（卡执业证、卡科班、卡 3 年经验）已经整批从列表里拿掉了，共 116 条——留着只会浪费点击，投了也是白投。想一次看全「我能投的」，两个都选上就行（多选会取并集）；数据本身还在本地 data/jobs_unified.json 里，等拿到执业证或补了规培，改一行就能让它们回来。

方式里为什么单独一列「沟通协调」：你说的是抵触陌拜，不是抵触沟通——ENFJ 本来就从人身上拿能量。所以「客户开发」（要主动敲不认识的门、背开发指标、被考核排名）和「沟通协调」（天天和人打交道，但对象是确定的：患者、学员、已有客户、同事）必须分开。前者才是你要躲的，后者是你能干的。快捷栏的「不陌拜」就是把这个区分做成一键：只排掉客户开发，沟通协调、院内固定、多院外勤、后台文档全留着。

营养健康这条线现在收到什么：营养师、临床营养、健康管理师、体重/慢病管理、功能食品与特医食品的注册。为什么值得看——临床医学懂病、懂禁忌、懂依从性，转营养是同一套知识换个用法，不用从零学。但两个证要说清：注册营养师（中国营养学会）要求营养相关专业或修过规定课程＋实习，临床医学本科能不能直接报要看学校课程，别想当然；健康管理师（人社第三方评价）门槛低得多，几周培训就能考。这两者的差别，直接决定了你起步能拿多少。

你问的三类，分开说，因为供给差别很大——赛道行里的「体检与健康管理」（72 条）就是这一栏：

· 医院临床营养科：站内基本没有，原因不是没岗位，是公立医院营养科走事业单位公开招聘（公告发在当地人社局、医院官网），不上招聘网站，抓不到；民营医院的营养科又极少单设。这条路要自己盯公告，或者先以「营养技师/营养护士」的身份进科室。
· 体检中心健康管理岗：美年、爱康、慈铭这类，站内有岗，但要认清一件事——「健康顾问」「健康管理顾问」在体检中心基本都是卖体检套餐，背业绩、要开拓企业客户。真想做「报告解读/总检/健康管理方案」这种专业活，岗位名通常是「总检医师助理」「报告解读」「健康管理师（非销售）」，看到「顾问」两个字先问一句：有没有业绩指标。
· 健康管理公司的医学支持岗：这一类最对口。慢病管理公司、营养科技公司、医学内容公司要的是「懂病、能看懂指南、能写能讲」的人，做医学内容审核、产品医学逻辑、客户方案支持。站内「医学编辑/医学支持」这类就是，工作方式多是后台文档，不背销售指标。门槛卡在能不能把专业话讲成用户听得懂的话。

赛道和方向不是一回事：「方向」是你进去干什么（临床研究 / 药物警戒 / 数据管理 / 注册质量 / 医学事务 / 产品 / 临床支持 / 销售…），「赛道」是这家公司在哪个行业（器械与诊断 / 医美 / 医疗AI / 数字健康 / 药企 / CRO / 医院）。同是临床支持，可能在器械厂、医美厂、AI 公司。两个筛选可以叠加，比如「赛道=医美 + 方向=产品」。

为什么要单列「方式」：方向和赛道说的都是「干什么」和「在哪干」，没说清「每天要面对谁」。同样是医疗器械公司，做注册是坐办公室写资料，做销售是天天敲陌生的门，做技术专员是进手术室站到半夜。这三件事对同一个人是完全不同的消耗，所以单独一栏：后台文档（对文件和数据，基本不见陌生客户）、院内固定（固定在一家机构，对着一小圈熟悉的人）、多院外勤（跑几家医院，对象是医生、不背开发指标）、客户开发（开发陌生客户 + 背指标 + 被考核）、手术跟台（进手术室，跟台次走、有射线）。你说过陌拜难、也不想跟台，那就用快捷里的「少对生人」——它等于后台文档 + 院内固定两类。

「小而美」是怎么判的：非大厂名单 + 平台标注 100–499 人。没有官方定义，只能说清口径：这一档人不多、层级少、一条业务线一两个人，学东西快、能碰到全流程。为什么下限是 100 不是 20——平台自己填的人数不可信（见过 4 个人的贸易公司标 100-999 人），几十人的皮包公司和几十人的专业小公司，在数据上分不出来，所以不往下放。标了「小而美」不等于背书：稳定性和大厂是反的，投之前务必问到三件事——社保按什么基数交、公司靠哪几个客户活着、上一轮融资是什么时候。人数判不出来的（外部来源很多没这个字段）一律不打标，不拿这个词当无信息的美化。

医美怎么收：收三类——厂家侧的器械/产品/临床培训/ToB 销售，机构侧的医助、医师助理（协助主诊医生做治疗配合、换药、写病历、术后回访），以及光电/注射类设备的临床应用岗。美容院的美容师、店长、医美咨询师、护肤品导购一律不收——那些跟你临床医学的背景没关系，也没有发展路径。

医助要注意什么：这是医美这条线里唯一真正吃临床专业、而且能走到「医生」的一类岗——临床医学本科毕业，在执业医师指导下、在医疗机构工作满一年，就能报考执业医师资格考试，之后可以转到医美医生。代价是起薪低（单体门诊普遍 5–8K）、前一年基本在做配合工作的杂事。另外，雇主标了「需助理医师执业证」的岗位你现在投不了：这个证同样要工作满一年才够报名条件，毕业当年拿不到，所以这部分单独打了红标，并给了「医助·现在能投」的快捷筛选。医助主体多是 20–99 人的单体门诊，这类会打「小机构」标，社保、底薪、提成方式务必面谈问到书面。

医疗AI为什么条数少：这个赛道对临床本科开放的岗位本来就窄。AI 公司的多数职位是算法/开发（要硕士和技术栈，本站直接排除），剩下能投的是医学影像解读、临床数据管理、医学编辑这类——但实际翻下来，江浙沪这批岗位多数要求 1-3 年经验或公司只有 20-99 人，两条都不满足你的条件，所以收录得很少。宁可空着，不拿「AI 医疗」的名头塞算法岗充数。

医药代表只收外企：国产药企的药代（底薪低、指标硬、靠带金销售）一条都不收；辉瑞、默沙东、阿斯利康、诺华、赛诺菲、GSK、罗氏、拜耳、诺和诺德、礼来、勃林格、武田、晖致这类外企的医学信息沟通专员会收，并单独标注——待遇、培训体系、合规要求和履历价值跟国产药代完全是两回事。这条是按你的要求放的，投不投你自己判断。

公司靠不靠谱：平台的「公司规模」字段不可信——有 4 个人的贸易公司标着 100-999 人，名字还蹭「瑞金」这种医院招牌。所以除了按公司名匹配白名单，还维护一份人工核验过的黑名单（data/blacklist.json），只放有工商登记、公开报道这类实据的，不放主观印象。核验方式是查工商登记（成立时间、注册资本实缴、参保人数、经营范围）＋公开报道＋在职评价，只看能被第三方证实的东西；小红书、抖音这类内容要登录态，程序抓不到，也不该编。

康强医疗人才网这条补充了什么：智联上医助、病案、医务科、医保办、导诊这类院内岗很少，因为民营医院和门诊部主要不在智联发。康强是医疗垂直站，这批岗在那边最集中，所以单独接了进来——抓取时逐条打开详情页，只收页面明确标「招聘中」的，停止招聘的直接丢。它的缺点也得说清楚：不提供可信的发布时间（页面上那个日期是服务端按当天渲染的，连排在后面的老岗也是今天），所以这批卡片不显示「挂了多久」，也不进「长期在招」判断。判断它还在不在，只能靠本站每天重新打开确认一次；连着几天打不开或状态变了就自动下线。

来源怎么分：按链接实际落地的网站判定，不按数据从哪抓的算。「招聘平台」是第三方网站（智联、猎聘、康强医疗人才网等）；「公司官网直招」是雇主自建的招聘页（多为北森、摩卡这类招聘系统），这类岗位绕过平台直接投；另外单列「高校就业网」和「猎头中介」。筛选区的「来源」是渠道粗分，「网站」才是具体哪一家。

为什么之前没有 BOSS，现在有了：登录态的 BOSS 抓不到（要设备验证），但匿名公开搜索页是可以的——用真实 Chrome 打开，再在页面里调它自己的搜索接口，不登录、不碰账号。代价是能看到的少三样，都写在上一条里了（薪资隐藏、只看第一页、没有发布日期）。所以这批岗的特点是：能点开、确认在招，但薪资得自己点进去看。如果你更想在 BOSS 里自己搜，用这几个词更省事： 临床医学 · 临床支持 · 医疗器械产品经理。 找到合适的，把链接发来，手工核验后一样可以进站。

「新接入」是个什么标签：新接一个来源时，会把它当时的存量岗一次性收进来（BOSS 这批就是）。这些岗对你确实是「今天才第一次看到」，但不是「今天才发布」，所以单独标「新接入」、不占「今日新增」的名额——否则接一个来源，今日新增会从一百多跳到几百，真实日增量就看不见了。次日起抓到的才是真新增，标「今日新增」。已经剔除的两类：要执业证的（口腔助理医师、中医助理医师这类）、以及兼职/日结/挂靠/「营养师变现」这类做不出可迁移能力的岗，都不再出现在列表里；要资历的（主任、总监、经理、主管）也剔了——带「助理」「专员」的除外，那是起步岗。

大厂判定：按公司名匹配白名单（外资器械 / 国产头部 / 头部药企 / 头部 CRO / 头部诊断），只做分类标记，不代表对雇主的推荐或背书。

没收录的方向，以及为什么——这条比收录了什么更重要，省得你以为「站里没有＝这条路上没岗」：

· 健康险核保 / 核赔：医学背景优先，坐在办公室看病历判赔不赔，性格上很合适。但雇主是保险公司，按你最早定的口径（保险理财类一律不收）被挡在外面了。真要走这条，我可以单独开一栏收，只是它会把你带离医疗行业。
· 疾控 / 卫健系统 / 公立医院行政：走事业单位公开招聘考试（一般每年 3–5 月、9–11 月两批），公告发在当地人社局和医院官网，不走招聘网站，本站抓不到。这是临床医学本科很实在的一条路，建议自己盯「浙江省/江苏省人社厅事业单位招聘」和各县市卫健局公告。
· 第三方医学检验所（金域/迪安/艾迪康这类）：检验岗要《临床医学检验技术》资格证，临床医学专业不对口；剩下能投的是标本接收、报告录入这类，专业用不上，所以没单列。
· 医药电商 / 连锁药房：执业药师方向，要药师证，且本质是零售。
· 高校科研助理：项目制、一年一签，多数要硕士；本科能投的偏样本库、动物房管理，成长性有限。
